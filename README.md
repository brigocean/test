# Тестовое задание - тема с системой лайков (WordPress)

Тема выводит на главной странице анонсы статей и добавляет к каждой карточке
систему лайков/дизлайков со своей таблицей в БД и страницей статистики в админке.

## Что сделано

- Тема 'likes-theme' (главная страница из макета, mobile-first).
- Лайки и дизлайки по каждой статье в анонсе.
- один голос на пользователя (по IP) на статью, с возможностью переголосовать
  и снять свой голос повторным кликом.
- Голоса пишутся в кастомную таблицу 'wp_article_likes' (не в postmeta):
  IP, адрес страницы, время, статья, значение голоса.
- Страница в админке "Лайки статей" - общая статистика (за / против / всего)
  на базе 'WP_List_Table', с сортировкой.
- Фронт без jQuery, Bootstrap и сторонних библиотек: чистые CSS и JS, flexbox/grid.

## Установка

1. Скопировать папку 'likes-theme' в 'wp-content/themes/'.
2. В админке WordPress: "Внешний вид - Темы" - активировать тему **Likes**.
   При активации создаётся таблица 'wp_article_likes'.
3. Импортировать контент из предоставленного бэкапа (если он ещё не залит).
4. Открыть главную страницу - появятся карточки статей с кнопками голосования.
5. Статистика: в админке пункт меню "Лайки статей".

## Структура

likes-theme/
  style.css                      заголовок темы
  functions.php                  подключение стилей/скриптов, поддержка темы
  header.php / footer.php
  index.php                      главная: цикл анонсов + кнопки лайков
  assets/css/main.css            вёрстка (mobile-first)
  assets/js/likes.js             отправка голоса через admin-ajax, чистый JS
  inc/likes.php                  таблица, подсчёт голосов, AJAX-обработчик
  inc/admin-stats.php            страница статистики на WP_List_Table

## Таблица 'wp_article_likes'

| поле | назначение |
|------|-----------|
| id | первичный ключ |
| post_id | статья |
| vote | 1 (лайк) или -1 (дизлайк) |
| ip | IP пользователя |
| page_url | страница, где поставили голос |
| created_at | время |

Уникальный ключ '(post_id, ip)' гарантирует один голос на пользователя на статью.
